# SCI Pharmaceutical POS & Supply Chain System

![SCI Logo](Logo.png)

A comprehensive, professional POS and Supply Chain Management solutions developed specifically for **Sudan Chemical Industries (SCI)**. Version 3.0.0 (Stable).

## Key Features

- **🛡️ Secure Quality Control (QC)**: Comprehensive batch release/reject module with full documentation and operator tracking.
- **💱 Multi-Currency Purchases**: Support for both Local (SDG) and Foreign (USD) currencies with real-time exchange rate management.
- **📜 Audit Trail**: Robust logging system that tracks every critical transaction and administrative action.
- **👥 User Management**: Full administrative control over system users, roles, and permissions.
- **📦 Inventory & Storage**: Real-time stock tracking with adjustment and adjustment locking.
- **📊 Reporting**: Detailed financial and operational reports.

## System Requirements

- **Operating System**: Windows 10/11
- **Framework**: .NET Framework 4.7.2
- **Database**: SQL Server 2016 or later
- **Screen Resolution**: Minimum 1366x768 (Optimized for 1080p)

## Getting Started

1. **Database Setup**: Run the SQL scripts in the `Database/` folder to initialize the system.
2. **Configuration**: Use the built-in Connection Form on the first launch to link the app to your SQL Server.
3. **Login**: Standard administrative credentials (see documentation).
